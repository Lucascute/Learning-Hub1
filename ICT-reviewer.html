Quick Review • Lessons 1–10

1. Introduction to Computer Programming

Programming – creating instructions that a computer can execute.

Examples of programming languages: Python, Java, C++, JavaScript
⭐ Programming = giving instructions to a computer.

2. Computer Ergonomics

Ergonomics focuses on safe and comfortable computer use.

  • Correct posture
  • Proper monitor position
  • Comfortable keyboard position
  • Regular breaks
⭐ Remember: Comfort + Safety + Proper Posture

3. HTML

HTML = Hypertext Markup Language.

  • <h1> = heading
  • <p> = paragraph
  • <a> = link
  • <img> = image
⭐ HTML creates the structure of a webpage.

4. HTML Editor

An HTML editor is used to create and edit HTML files.

Examples: Visual Studio Code, Notepad, Notepad++

⭐ HTML files use the .html extension.

5. HTML Headings, Paragraphs and Styles

  • <h1> to <h6> = headings
  • <p> = paragraph
  • <b> = bold
  • <i> = italic
  • <u> = underline
⭐ HTML = content and structure.

6. Embedding Multimedia

Webpages can contain:

  • Images
  • Audio
  • Video
Image: <img>
Audio: <audio>
Video: <video>

7. Basic Webpage Design

Good webpage design should be organized, readable, attractive, and easy to navigate.

Important: Colors • Spacing • Fonts • Layout • Navigation

8. CSS

CSS = Cascading Style Sheets.

CSS controls the appearance of webpages.

  • Colors
  • Fonts
  • Backgrounds
  • Spacing
  • Borders
  • Layout
⭐ CSS = Design

9. CSS Styling and Layout

Common CSS properties:

  • color
  • background-color
  • font-size
  • margin
  • padding
  • border
⭐ Padding = inside spacing
⭐ Margin = outside spacing

10. Website Development

Website development is the process of creating and maintaining websites.

HTML → Structure
CSS → Design
JavaScript → Behavior
⭐ Basic process: Plan → HTML → Content → CSS → Test → Publish

🧠 Quick ICT Memory Guide

HTML = Structure

CSS = Style / Design

JavaScript = Interaction / Behavior

.html = HTML file extension

<h1> = Heading

<p> = Paragraph

<img> = Image

<audio> = Audio

<video> = Video
