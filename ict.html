Lesson 1: Introduction to Computer Programming

Computer programming is the process of creating instructions that a computer can understand and execute.

What is Programming?

Programming involves writing a set of instructions called code to make a computer perform a specific task.

Programming Language

A programming language is a formal language used to communicate instructions to a computer.

Examples:
  • Python
  • Java
  • C++
  • JavaScript
  • HTML
  • CSS

Basic Programming Concepts

  • Variables
  • Data
  • Operators
  • Input
  • Output
  • Conditions
  • Loops
Remember: A program is a set of instructions designed to solve a problem or perform a task.

Lesson 2: Computer Ergonomics

Computer ergonomics refers to arranging and using computer equipment in a way that promotes comfort, safety, and efficiency.

Proper Computer Posture

  • Keep your back straight.
  • Keep your feet flat on the floor.
  • Relax your shoulders.
  • Keep your wrists in a comfortable position.
  • Keep the monitor at a comfortable eye level.

Healthy Computer Habits

  • Take regular breaks.
  • Avoid staring at the screen for too long.
  • Keep proper distance from the monitor.
  • Keep your workspace organized.
💡 Study Tip: Remember the goal of ergonomics: comfort, safety, and proper posture.

Lesson 3: Hypertext Markup Language (HTML)

HTML stands for Hypertext Markup Language. It is the standard markup language used to structure webpages.

Basic HTML Structure

<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>

<body>
    <h1>Hello World</h1>
    <p>This is my webpage.</p>
</body>
</html>

Common HTML Elements

  • <html> – root of the webpage
  • <head> – contains webpage information
  • <title> – webpage title
  • <body> – visible content
  • <h1> – heading
  • <p> – paragraph
  • <a> – hyperlink
  • <img> – image

Lesson 4: HTML Editor

An HTML editor is a software application used to create and edit HTML documents.

Examples of Editors

  • Visual Studio Code
  • Notepad
  • Notepad++
  • Sublime Text

Basic Workflow

  1. Open an HTML editor.
  2. Create an HTML file.
  3. Write the HTML code.
  4. Save the file using .html.
  5. Open the file using a web browser.
  6. Check and edit the webpage.
Important: HTML files normally use the .html file extension.

Lesson 5: HTML Headings, Paragraphs, and Styles

Headings

HTML provides headings from <h1> to <h6>. 

<h1>Main Heading</h1>
<h2>Subheading</h2>
<h3>Smaller Heading</h3>

Paragraph

<p>This is a paragraph.</p>

Text Formatting

  • <b> – bold text
  • <i> – italic text
  • <u> – underlined text

Inline Styling

<p style="color: blue;">
Blue text
</p>

Lesson 6: Embedding Multimedia Elements in a Webpage

Multimedia allows webpages to contain images, audio, video, and other media.

Adding an Image

<img src="picture.jpg" alt="My Picture">

Adding Audio

<audio controls>
    <source src="music.mp3">
</audio>

Adding Video

<video controls width="500">
    <source src="video.mp4">
</video>
💡 Always use alt text for images to improve accessibility.

Lesson 7: Basic Webpage Design

Webpage design focuses on making a website organized, readable, attractive, and easy to use.

Important Design Principles

  • Good organization
  • Readable text
  • Consistent colors
  • Proper spacing
  • Clear navigation
  • Responsive layout

Example

<style>
body {
    font-family: Arial;
    background-color: lightblue;
}

h1 {
    color: navy;
}
</style>

Lesson 8: Introduction to CSS

CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of webpages.

CSS Can Change

  • Colors
  • Fonts
  • Spacing
  • Backgrounds
  • Borders
  • Element sizes
  • Page layout

Example

body {
    background-color: white;
    font-family: Arial;
}

h1 {
    color: blue;
}

Lesson 9: CSS Styling and Layout

CSS can be used to create organized layouts and attractive webpage components.

Common CSS Properties

  • color – text color
  • background-color – background color
  • font-size – text size
  • margin – outside spacing
  • padding – inside spacing
  • border – element border
  • width – element width
  • height – element height

Simple Card

.card {
    background: white;
    padding: 20px;
    margin: 10px;
    border-radius: 10px;
}

Lesson 10: Website Development

Website development is the process of creating and maintaining websites using technologies such as HTML and CSS.

Basic Parts of a Website

  • HTML – structure and content
  • CSS – design and appearance
  • JavaScript – interaction and behavior

Website Development Process

  1. Plan the website.
  2. Create the HTML structure.
  3. Add content.
  4. Apply CSS styling.
  5. Add interactive features when needed.
  6. Test the website.
  7. Publish the website.
💻 Remember:

HTML = Structure
CSS = Design
JavaScript = Behavior
