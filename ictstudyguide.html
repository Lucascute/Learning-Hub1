💻 Lesson 1 — Introduction to Computer Programming

What is computer programming?

Computer programming is the process of creating instructions that a computer can follow to perform a specific task or solve a problem.

Important Terms

  • Program – a set of instructions given to a computer.
  • Programming Language – a language used to communicate instructions to a computer.
  • Programmer – a person who writes and develops computer programs.
  • Algorithm – a step-by-step procedure for solving a problem.
💡 Remember:

A computer follows instructions. Programming allows people to give those instructions clearly and logically.

🪑 Lesson 2 — Computer Ergonomics

What is computer ergonomics?

Computer ergonomics is the practice of arranging and using computer equipment in a way that promotes comfort, safety, and efficiency.

Proper Computer Ergonomics

  • Sit with your back properly supported.
  • Keep your feet comfortably on the floor.
  • Keep the monitor at an appropriate height.
  • Keep your wrists in a comfortable position.
  • Take regular breaks from the screen.
  • Maintain proper distance from the monitor.
⚠️ Why is it important?

Good ergonomics can help prevent discomfort, eye strain, back pain, neck pain, and repetitive strain injuries.

⌨️ Lesson 3 — Programming Basics

Basic programming concepts

Programming requires logical thinking and understanding how instructions are organized.

Common Concepts

  • Input
  • Process
  • Output
  • Sequence
  • Decision
  • Repetition
Example:

A simple calculator receives numbers as input, performs a calculation as the process, and displays the answer as the output.

🔢 Lesson 4 — Variables and Data

What is a variable?

A variable is a named location used to store information that a program can use.

Common Data Types

  • Integer – whole numbers.
  • Float – numbers containing decimals.
  • String – text or characters.
  • Boolean – True or False values.
name = "John"
age = 16
score = 95.5
passed = True
💡 Remember:

Variables allow programs to store and work with information.

🔀 Lesson 5 — Conditional Statements

What are conditional statements?

Conditional statements allow a program to make decisions based on whether a condition is true or false.

if score >= 75:
    print("Passed")
else:
    print("Failed")

Common Conditional Statements

  • if
  • if-else
  • if-elif-else
💡 Study Tip:

Look carefully at the condition before deciding what the program will do.

🔁 Lesson 6 — Loops

What is a loop?

A loop repeatedly executes a block of code while a particular condition is met.

Common Types

  • For Loop – repeats a specific number of times or over a sequence.
  • While Loop – continues while a condition remains true.
for i in range(5):
    print(i)
⚠️ Watch Out:

A loop must eventually reach a condition that stops it when using a condition-controlled loop.

📦 Lesson 7 — Functions

What is a function?

A function is a reusable block of code designed to perform a particular task.

def greet():
    print("Hello!")

greet()

Advantages of Functions

  • Reduce repeated code.
  • Make programs easier to organize.
  • Make code easier to understand.
  • Allow code to be reused.

🐞 Lesson 8 — Debugging

What is debugging?

Debugging is the process of finding and fixing errors in a computer program.

Common Types of Errors

  • Syntax Error – an error in the structure or rules of the code.
  • Runtime Error – an error that occurs while the program is running.
  • Logic Error – the program runs, but produces an incorrect result.
💡 Debugging Tip:

Read the error message carefully and check the code around the line where the error occurred.

🛡️ Lesson 9 — Computer Safety

Why is computer safety important?

Computer safety protects both the user and computer equipment from accidents, damage, and unsafe practices.

Safety Practices

  • Keep liquids away from computers.
  • Handle devices carefully.
  • Keep cables organized.
  • Do not overload electrical outlets.
  • Use proper posture.
  • Keep software updated.
⚠️ Remember:

Physical safety and digital safety are both important when using computers.

🌐 Lesson 10 — Responsible ICT Use

What is responsible ICT use?

Responsible ICT use means using technology safely, ethically, respectfully, and legally.

Responsible Practices

  • Respect other people's privacy.
  • Use strong passwords.
  • Do not share personal information carelessly.
  • Give credit to original creators.
  • Avoid cyberbullying.
  • Think before posting online.
  • Use reliable sources of information.
💡 Digital Citizenship:

Good digital citizens use technology responsibly and treat other people with respect online.

⭐ ICT Study Tips

  1. Understand the concept first. Don't just memorize programming terms.
  2. Practice writing code. Reading code is different from actually creating it.
  3. Learn from errors. Errors are a normal part of programming.
  4. Memorize important terminology. Know the difference between variables, functions, loops, and conditions.
  5. Practice step-by-step. Break complicated problems into smaller tasks.
  6. Review computer safety. Don't focus only on programming.
  7. Be a responsible digital citizen. Use technology safely and respectfully.
