WEEK 1

Law of Sines and Ambiguous Case

The Law of Sines is used to solve oblique triangles when certain sides and angles are known.

Formula

a / sin(A) = b / sin(B) = c / sin(C)

Example

Given A = 30°, B = 45°, and a = 10.

Find b.

b / sin(45°) = 10 / sin(30°)

b = 10(sin45° / sin30°)

b ≈ 14.14

Ambiguous Case

The ambiguous case occurs when two sides and a non-included angle are known. This is called SSA.

  • No triangle
  • One triangle
  • Two triangles
Remember: The ambiguous case is associated with SSA.
WEEK 2

Law of Cosines

The Law of Cosines is used to solve oblique triangles. It is commonly used with SAS and SSS.

Formula

c² = a² + b² - 2ab cos(C)

Example

Given a = 5, b = 7, and C = 60°.

c² = 5² + 7² - 2(5)(7)cos60°

c² = 25 + 49 - 70(0.5)

c² = 39

c ≈ 6.24

Remember: SAS or SSS usually means Law of Cosines.
WEEK 3

Word Problems with Sines, Cosines and Bearings

Bearings

A bearing describes direction measured clockwise from North.

  • North = 000°
  • East = 090°
  • South = 180°
  • West = 270°

Example

A boat travels 10 km east. Another boat travels 10 km north.

The angle between the paths is 90°.

c² = 10² + 10² - 2(10)(10)cos90°

c² = 200

c ≈ 14.14 km

Steps

  1. Read the problem.
  2. Draw a diagram.
  3. Mark the bearings.
  4. Find the required angle.
  5. Choose Law of Sines or Law of Cosines.
  6. Solve and include the correct unit.
WEEK 4

Transformations on the Cartesian Plane

Translation

(x, y) → (x + a, y + b)

Example

Move (2, 3) four units right and two units down.

(2, 3) → (2 + 4, 3 - 2)

Answer: (6, 1)

Reflection

Across x-axis: (x,y) → (x,-y)

Across y-axis: (x,y) → (-x,y)

Across origin: (x,y) → (-x,-y)

Rotation

90° counterclockwise: (x,y) → (-y,x)

180°: (x,y) → (-x,-y)

270° counterclockwise: (x,y) → (y,-x)

Dilation

(x,y) → (kx,ky)

Example: Dilate (3,4) by a scale factor of 2.

(3,4) → (6,8)

WEEK 5

Solving Quadratic Inequalities

A quadratic inequality contains a variable raised to the second power and an inequality symbol.

Example

Solve:

x² - 5x + 6 > 0

Factor:

(x - 2)(x - 3) > 0

Critical numbers: x = 2 and x = 3

Answer: x < 2 OR x > 3

Steps

  1. Move everything to one side.
  2. Factor the quadratic.
  3. Find the critical numbers.
  4. Make a number line.
  5. Test the intervals.
  6. Write the solution.
WEEK 6

Quadratic Inequalities with One Variable

Example

Solve:

x² + x - 6 ≤ 0

Factor:

(x + 3)(x - 2) ≤ 0

Critical numbers: x = -3 and x = 2

Answer: -3 ≤ x ≤ 2

For ≤ or ≥, include the critical numbers. For < or >, do not include them.
WEEK 7

Absolute Value Equations

Absolute value represents distance from zero.

Basic Rule

|x| = a

x = a OR x = -a

Example

Solve:

|x - 3| = 5

x - 3 = 5

x = 8

OR

x - 3 = -5

x = -2

Answer: x = 8 or x = -2

WEEK 8

Absolute Value Inequalities

Important Rules

|x| < a → -a < x < a

|x| ≤ a → -a ≤ x ≤ a

|x| > a → x < -a OR x > a

|x| ≥ a → x ≤ -a OR x ≥ a

Example

Solve:

|x - 2| < 4

-4 < x - 2 < 4

Add 2:

-2 < x < 6

Less than means the solution is between the values. Greater than means the solution is outside the values.
WEEK 9

Measures of Position

Measures of position tell us where a value is located within a data set.

Quartiles

  • Q1 = 25th percentile
  • Q2 = 50th percentile
  • Q3 = 75th percentile

Example

Data:

2, 4, 5, 7, 8, 10, 12, 15

Lower half:

2, 4, 5, 7

Q1 = (4 + 5) / 2

Q1 = 4.5

Upper half:

8, 10, 12, 15

Q3 = (10 + 12) / 2

Q3 = 11

Always arrange the data from smallest to largest first.
WEEK 10

Percentile Rank

Percentile rank tells us the relative position of a score compared with other scores.

Formula

Percentile Rank = (Number of values below the score / Total number of values) × 100

Example

There are 20 students.

A student scored higher than 15 students.

Percentile Rank:

(15 / 20) × 100

= 75%

Therefore, the student is approximately at the 75th percentile.
